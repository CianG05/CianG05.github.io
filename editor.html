Roadmap-Daten bearbeiten

So hältst du die Roadmap aktuell

  1. Status ändern: planned, in_progress oder done.
  2. Bei erledigten Aufgaben status auf done setzen.
  3. Datum unter updated aktualisieren.
  4. Datei herunterladen.
  5. Die vorhandene roadmap.json im Repository ersetzen.

Direkt in GitHub geht es noch einfacher über den Button „Roadmap bearbeiten“ auf der Hauptseite.
