JuH BaustellenHub – Büro-Test-Build
====================================

Was ist das?
------------
Eine Testversion der App „JuH BaustellenHub“ für den internen Büro-Test
auf Windows-PC und Android-Tablet. Zweck: Funktionen und Anbindung an
den Server prüfen, ohne produktiven Login-Ablauf.

Inhalt dieses Pakets
--------------------
- Windows\     … komplette Windows-App (EXE inkl. aller benötigten Dateien)
- Android\     … Installationsdatei für Android-Tablets (APK)

Voraussetzungen
---------------
- Internetverbindung nötig (die App spricht mit dem Server auf Render).
- Windows: aktueller Windows-PC (64-Bit).
- Android: Tablet/Smartphone mit Möglichkeit, Apps aus unbekannten
  Quellen zu installieren (je nach Geräteeinstellung).

Windows starten
---------------
1. Ordner „Windows“ öffnen.
2. Die Datei „juh_baustellenhub.exe“ doppelklicken.
3. Den gesamten Ordner „Windows“ zusammen lassen – die EXE allein
   funktioniert nicht ohne die anderen Dateien daneben.

Android installieren
--------------------
1. Die Datei „JuH-BaustellenHub-Buero-Test.apk“ auf das Tablet kopieren
   (USB, E-Mail, Cloud o. Ä.).
2. Auf dem Gerät die APK öffnen und der Installation zustimmen.
3. App starten.

Login / Anmeldung
-----------------
In dieser Büro-Test-Version entfällt die normale Anmeldung, sofern der
Server entsprechend für den Test konfiguriert ist. Sie können die App
direkt nutzen.

Bei Verbindungsfehlern
----------------------
- Internetverbindung prüfen.
- Firewall/VPN prüfen, ob der Zugriff auf den Render-Server möglich ist.
- Kurz warten und erneut starten (Server kann beim ersten Aufruf
  „aufwachen“).

Hinweise
--------
- Nur für internen Büro-Test bestimmt.
- Bitte den kompletten Ordner bzw. die ZIP weitergeben, nicht nur
  einzelne Dateien aus „Windows“.
